# AGENTS.md — toolkit

Библиотека, которую используют несколько проектов. Любая правка здесь — правка у всех потребителей.

## Гейт

```sh
npm run test:unit && npm run typecheck && npm run lint && npm run build
```

## Правила

- Модуль переносится вместе с тестами. Без теста модуль в toolkit не попадает.
- Зависимости передаются параметром (токен, `fetch`, клиент БД, `env`). Глобальное состояние и
  чтение `process.env` внутри логики не допускаются. Исключение — значения по умолчанию, и они
  описаны в README модуля.
- Бизнес-специфичное (номера тем, список стеков, тексты карточек) остаётся в проектах и передаётся
  конфигом.
- Ломающее изменение экспорта повышает MAJOR, и в CHANGELOG пишется инструкция миграции.
- Код пишется так, чтобы `node --experimental-strip-types` его понимал: никаких parameter properties,
  `enum` и `namespace`.
- Импорты внутри пакета — относительные с расширением `.ts`. tsc переписывает их в `.js` при сборке.
- Новый модуль: `src/<домен>/`, `index.ts` домена, запись в `exports` в `package.json`, строка в
  таблице README.
- Релиз: CHANGELOG, `VERSION` и `package.json`, тег `vX.Y.Z`, push с тегами.
